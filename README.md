# 学习守护 · 五年级晚间学习闭环

一个「不下班、不带情绪的指令源」。孩子端是每日路线和专注计时，家长端是看板和返工，
两端共用一个账号、同一份云端数据。

## 一·五、公开版占位符（clone 后必读）

本仓库是**公开版源码**，所有指向作者私有实例的配置都已替换为 `YOUR_*` 占位符。
不替换的话页面连不上云端，这是预期行为。

| 占位符 | 所在文件 | 换成 |
|---|---|---|
| `YOUR_APP_HOST` | `web/index.html` 顶部 | 你的应用域名，形如 `xxx.app.workbuddy.host` |
| `YOUR_SHARECODE` | 同上 | 你的分享码 |
| `YOUR_PUBLISHABLE_KEY` | `web/assets/cloud.js` 的 `CLOUD_CONF` | 你的云服务 publishableKey |
| `YOUR_APP_ID` | README 部署说明 | 你的发布应用 ID |
| `YOUR_WECHAT_APPID` | `web/index.html`、`web/assets/vendor/cloud-sdk*.js` | 见下方说明 |
| `YOUR_DOC_ID` / `YOUR_PAGE_ID` | README、安卓壳注释 | 你自己的资料库文档 / 发布页 ID |

> `YOUR_WECHAT_APPID` 云 SDK 里的小程序 AppID 只在 `platform.navigate()` 的微信小程序授权分支使用；
> 网页端登录走 `oauthRelayBaseUrl`，**保持占位符不影响网页运行**。
> 公开仓库不放真实 AppID、sharecode、publishableKey、签名密钥或离线数据。

### 部署铁律（2026-11-03 踩坑后定）

发布应用的记录是**按目录绑定**的。主域这条记录绑在 **C 盘目录**
`C:\Users\Administrator\WorkBuddy\2026-10-29-20-01-44\outputs\study-guardian\web`，
D 盘目录（源码工作区）绑的是另一条记录，直接用 D 盘目录发布会**新建另一个域名**，
孩子端访问的主域反而还是旧版。

正确流程：

1. 改代码 → 改 D 盘 `D:\WorkBuddy\2026-10-29-20-01-44\outputs\study-guardian\web`
2. 同步到 C 盘同名 `web` 目录（`index.html` + `assets/` 整体覆盖）
3. 用 **C 盘目录** 发布，并显式指定 `appId = YOUR_APP_ID`

这样链接恒定是 `YOUR_APP_HOST`，且云服务的 Origin 校验不会失效
（云接口只接受主域这个源，换域名登录会全部失败）。

## 二·六、凭证功能（v1.1.0）

**存储**：平台只放行 `runtime` 这一个 bucket。路径必须形如 `users/<uid>/...`，
通过 `client.storage.userPath(uid, 相对路径)` 生成，天然按用户隔离，配合 RLS 别人取不到。

**接口**（`web/assets/cloud.js`）：

| 方法 | 作用 |
|---|---|
| `Cloud.uploadEvidence(blob, day, taskId)` | 上传，返回 `{ ok, path }` |
| `Cloud.evidenceUrl(path, 秒)` | 换临时签名地址，默认 1 小时 |
| `Cloud.deleteEvidence(path)` | 删除 |

**数据库**：`day_tasks` 新增 `evidence_path` / `evidence_mime` / `evidence_at` 三列。

**几个踩过的坑**：

1. `userPath(e, t)` 的**第一个参数是 uid，不是路径**。传错会报
   `owner/user id is not a valid storage path segment`，这个提示很有迷惑性。
2. 本地 `http://127.0.0.1` 下 storage 接口一律 `Failed to fetch`（跨域），
   必须在线上域名才能测。auth 接口本地是通的，别被这一点误导。
3. iOS 上调相机必须 `<input type="file" capture="environment">` 且在点击的**同步调用栈**里
   `.click()`；原来那层 `setTimeout(320)` 会丢掉手势上下文，相机根本弹不出来。
4. `canvas.toBlob` 存 jpg 前要先铺一层白底，否则透明区域出黑块。
5. 录音 iOS 走 `audio/mp4`，安卓走 `audio/webm`，扩展名按类型给（mp4 → `.m4a`）。

**验证记录**（都已实跑，非推测）：照片 128 KB → 压到 22 KB，上传后签名地址取回 HTTP 200、
字节数一致；录音 `audio/mp4` 40 KB 同样一致；家长端点开「看照片」图片 `naturalWidth=1600` 正常渲染。
测试文件用 `zz-selftest` 前缀，跑完即删。

## 五、打 APK

```bash
cd android-shell
./build.sh                        # 孩子端 + 家长端，release
./build.sh assembleChildRelease   # 只打孩子端
./build.sh clean
```

产物在 `android-shell/app/build/outputs/apk/`：

| 包 | 包名 | 行为 |
|---|---|---|
| 孩子端 | `com.zhijue.studyguardian.child` | 全屏沉浸、返回键不出 App、连点左上角 7 次弹密码才能退出（默认 `123456`） |
| 家长端 | `com.zhijue.studyguardian.parent` | 全屏，返回键正常退出 |

**为什么 APK 加载线上地址而不是本地文件**：云服务的登录校验要求 Origin 与发布域名完全一致，
本地 `file://` 的 Origin 是 `null`，会被服务端拒绝。代价是 APK 必须联网；家里有 WiFi 就没问题。

安卓安装需在系统里允许「安装未知来源应用」，第一次要手动点一下。

## 七、已知边界

1. **APK 必须联网**，无离线缓存。断网时白屏，恢复网络刷新即可。
2. **孩子平板登的是家长账号**。已用三层防护：孩子端无登出入口、全屏锁定、家庭码可重置。
3. **同步是近实时的，不是即时推送**。孩子端记完，家长端最长 45 秒后才刷新（也可手动刷新）。
4. 兑换里的照片 / 录音目前是占位，还没接文件上传。

### 自托管配置（克隆后必改）
网页端两处配置已脱敏成占位符，需替换为你自己的 WorkBuddy 应用：
- `web/index.html` 顶部：`YOUR_APP_HOST`（应用域名）、`YOUR_SHARECODE`（分享码）
- `web/assets/cloud.js` 顶部 `CLOUD_CONF`：`endpoint`、`publishableKey`
（`oauthRelayBaseUrl` 是平台公共地址，不用改。）

未替换占位符时，页面会自动跳过域名规范化、不会死循环，但**连不上云端、不能登录**——仅适合读代码。

### 构建网页端
`web/` 即部署目录。用 WorkBuddy 资料库或任意静态托管发布 `web/`，入口 `index.html`。

### 构建学习守护 APK
```bash
cd android-shell
./build.sh assembleChildRelease     # 孩子端 com.zhijue.studyguardian.child
./build.sh assembleParentRelease   # 家长端 com.zhijue.studyguardian.parent
```
需自备 Android SDK，把 `local.properties` 的 `sdk.dir` 指向你的 SDK 目录（仓库已 `.gitignore` 该文件）。图标位图随仓库，无需额外生成。产物在 `android-shell/app/build/outputs/apk/`。

### 构建知识图谱 APK
```bash
cd android-shell-kg
./build.sh
```
**前置**：《中小学生知识图谱》资料库镜像（约 15MB，含 9.3MB 题库）需自行解压到
`android-shell-kg/app/src/main/assets/site/`（仓库因体积未纳入，见 `.gitignore`）。
页面经内置本地 HTTP 服务离线加载，装上即可用，不依赖网络。
